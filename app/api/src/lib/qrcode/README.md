# Bộ mã hóa QR Code

Mã nguồn "QRCode for JavaScript" – Copyright (c) 2009 Kazuhiko Arase, giấy phép MIT
(http://www.opensource.org/licenses/mit-license.php), bản chuyển sang Node.js lấy từ gói `qrcode-terminal`.
Giữ nguyên, không sửa. FreshVend dùng để vẽ mã VietQR thành SVG ngay trên máy chủ, nên màn hình kiosk
không phụ thuộc thư viện tải từ Internet.

"QR Code" là nhãn hiệu đã đăng ký của DENSO WAVE INCORPORATED.
